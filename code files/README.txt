RUN LOCALLY:
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html -> Open with Live Server.

GITHUB PAGES:
Upload all HTML/CSS/JS files to the repository root.
Then enable Settings -> Pages -> Deploy from branch -> main -> /(root).

NOTE:
The contact form opens the user's email application because GitHub Pages is static hosting and does not run the Hatchable database API.
